# Claude Harness

A starter repository for a local Claude Code development harness. The goal is to turn a task into a scoped implementation, test the running application with Docker Compose, and give the owner evidence for a release decision.

## Try the intake scaffold

Open this checkout in Claude Code and run `/harness-intake` with a project idea, bug report, or feature request. The skill drafts the task and asks about decisions that affect scope or acceptance. Review its output against the [example task](examples/task.json).

This scaffold includes project instructions, intake, and a [design outline](docs/design.md). Native hooks, the verification runner, and plugin distribution are implementation milestones.
